# 데이터 로딩/정제 (`data_fetcher.py`)

## 역할

원본 리포트 파일(parquet/xlsx) 로드 및 전처리 담당 모듈입니다.

## 주요 처리

- 최신 리포트 파일 탐색 및 로드
- 타입 정리(날짜/숫자/문자열)
- 매물 키 생성(`매물묶음키` 등)
- 정제된 부동산명 기반 중복 제거
- 그림자/중복 매물 제거

## 중복 제거 정책 (요약)

- 동일 시점/동일 키/동일 정제부동산명 조합은 1건으로 유지
- 노출 순위 기준 우선 행을 남기고 잔여 중복 제거

## 수정 시 주의사항

- 전처리 컬럼명을 바꾸면 `app.py`, `ranking_logic.py`에서 연쇄 영향 발생
- drop 기준 컬럼 변경 시, 대시보드 수치가 즉시 달라지므로 검증 필수
