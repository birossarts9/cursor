# App 구조 (`app.py`)

## 역할

`app.py`는 Streamlit 대시보드의 메인 엔트리입니다.

- 페이지 레이아웃 구성
- 사용자 입력(단지/지역/기간/부동산 필터) 처리
- 전처리/집계 함수 호출
- 최종 테이블/카드/차트 렌더링

## 주요 책임

- 세션 상태/필터 상태 관리
- 캐시된 데이터 호출
- 갱신 이벤트 데이터(`boosted_raw`, `boosted_df` 계열) 생성 후 분석 함수에 전달
- 결과를 UI 컴포넌트로 변환

## 의존 관계

- `data_fetcher.py`: 원본 데이터 로딩 + 전처리
- `ranking_logic.py`: 랭킹/빈도/추천 계산
- (기타 유틸/스타일): 포맷팅, 텍스트, 스타일링

## 수정 시 주의사항

- UI 변경과 집계 로직 변경을 분리해서 커밋
- 기간 필터(예: 최근 14일)와 실제 로딩 기간이 불일치하지 않도록 확인
- 대시보드 숫자는 "UI 기준 집계"인지 "raw 기준 집계"인지 명확히 표시
