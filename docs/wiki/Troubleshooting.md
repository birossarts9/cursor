# 트러블슈팅

## 증상: 대시보드 갱신 횟수가 엑셀과 다름

### 주된 원인

- 집계 기간 불일치 (예: raw 전체 vs 최근 14일)
- 중복 제거 기준 차이
- 부동산명 정규화 여부 차이
- 일요일 제외 규칙 적용 차이

### 확인 순서

1. 동일 매물 식별 키가 맞는지 확인
2. 동일 기간으로 재집계
3. 확인일자 `nunique` 기준으로 비교
4. 중복 제거 전/후 행 수 비교

---

## 증상: 특정 매물이 과도하게 많이 집계됨

### 가능 원인

- 동일 스펙 다중 고유번호 롤링
- CP 중복 전송/무료 그림자 매물 잔존
- 전처리 단계의 키/정규화 누락
